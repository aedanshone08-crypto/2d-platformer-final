This game is about a 2D learning game where you can learn a language or 2 depend on how much you do.
The game isn't fully finished but it is something that is some sort of playable.
It originaly going to have damage when the player got the question wrong and healed when they get it righ.
In addition the player would have got 100 health.
Some of the answers I would changed or updated because some not all had incorrect translation to it.

The movement is D for right, A for left and spacebar to jump.
I have done this game from September to December.
This is my first game project that I have done.
